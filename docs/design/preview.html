8 · Do’s & Don’ts

Do
  • Use semantic CSS variables — no hard-coded grays.
  • Primary CTA = ink; brand for focus / charts only.
  • People: status pills + filters, not dual org/team tabs.
  • Console density: 14px body, 8px control radius, soft elevation.
  • Keep light/dark component sets identical (this preview).
  • User-visible CJK only in locale files — not hard-coded in TSX (OMA-style checks).
Don’t
  • No mesh gradients / marketing heroes.
  • Don’t paste OMA three-column chat chrome into the control plane.
  • Don’t use brand blue for default Add / Save.
  • Don’t use rounded-full on ordinary CTAs.
  • Don’t restyle the app only from preview CSS — implement via theme.css.
