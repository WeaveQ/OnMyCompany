7 · Inputs & modal footer pattern

Focus ring = brand

输入 focus 使用 #7c9dff ring，按钮 primary 仍为 ink。这是 Linear 式「强调色克制」+ Cal 式「黑 CTA」的组合。

8 · Do’s & Don’ts

Do
  • 用 var(--primary) 等语义变量，不写死灰阶。
  • 主 CTA = ink；brand 仅 focus / chart。
  • 人员用状态 pill + 筛选，不双 Tab 两套名单。
  • 管控台密度：14px 正文、8px 控件圆角、轻阴影。
  • 中英文字体栈按 lang 切换。
Don’t
  • 不要 mesh 渐变 / 营销 hero（见 PRODUCT.md）。
  • 不要把 OMA 三栏聊天壳硬搬到企业管控台。
  • 不要用 brand 蓝当默认「添加 / 保存」。
  • 不要普通 CTA 用 rounded-full。
  • 不要为预览去改 web/src/styles/* 产品样式。

打开方式：本地直接打开本文件，或 open docs/design/preview.html。 对照 OMA：onmyagent/docs/design/preview.html。 实现 SoT 仍是 web/src/styles/theme.css；本预览独立 CSS，零耦合应用包。
