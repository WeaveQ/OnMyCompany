# 企业账号与团队

花名册回答「公司有谁」；团队回答「这个小队有谁」。先有企业账号，再入队。

产品入口：侧栏 **企业账号** `/members`、**团队** `/team`。全公司上下文时，「团队」会打开 **团队列表** `/org/teams`（不进侧栏）。

## 1. 和「…」有什么区别

|                | 企业账号                                  | 团队                                  |
| -------------- | ----------------------------------------- | ------------------------------------- |
| 管什么         | 邮箱、企业角色、启用 / 停用 / 删除        | 本队成员、队内角色、队名              |
| 谁能改         | 仅企业管理员                              | 企业管理员；或本队所有者 / 团队管理员 |
| 停用后果       | 所有队失效，会话和 runtime token 一并吊销 | 只离开这一队                          |
| 不在这里做的事 | 入队                                      | 改企业角色、从公司除名                |

## 2. 从哪里打开

1. 用企业管理员会话打开管理台。
2. 加人：侧栏 **企业账号**。
3. 建队：把切换器打到全公司，或从团队页进「全部团队」，点创建。
4. 入队：打开具体队，从企业账号池勾人。也可以填尚未入册的邮箱，由企业管理员路径一并建账号。

## 3. 企业账号

企业角色只有三项：

| 界面       | 代码      | 典型工作                                           |
| ---------- | --------- | -------------------------------------------------- |
| 员工       | `member`  | 登录、进被分配的队、自己执行与自己的用量           |
| 企业管理员 | `admin`   | 管花名册、建队、企业设置、Skills、全公司视图、审计 |
| 企业审计   | `auditor` | 只看用量、运行、审计；不能改人、改策略、改 Skills  |

能做的事：

| 操作           | 说明                                                        |
| -------------- | ----------------------------------------------------------- |
| 添加           | 邮箱、显示名、角色。新人是 Pending，第一次登录后才是 Active |
| 筛选           | 全部 / Pending / Active / Deactivated                       |
| 改角色或显示名 | 企业管理员                                                  |
| 停用           | 吊销该成员会话和绑定的 runtime token                        |
| 删除           | 硬删除账号，同样吊销凭证                                    |

最后一个 `admin` 不能停用或删除，接口会拒绝。没有单独的「企业所有者」字段，bootstrap 邮箱就是首个管理员。

普通员工打开此页是只读表。企业审计同样不能加人。

## 4. 团队

队名限制：`[A-Za-z0-9._-]{2,64}`，不能用中文名。

| 界面       | 代码          | 能力                       |
| ---------- | ------------- | -------------------------- |
| 团队所有者 | `creator`     | 建队人；不能降级、不能移出 |
| 团队管理员 | team `admin`  | 本队加人、改队角色、改队名 |
| 团队成员   | team `member` | 本队协作                   |

能做的事：

| 操作         | 说明                             |
| ------------ | -------------------------------- |
| 创建团队     | 企业管理员；在 `/org/teams`      |
| 打开本队     | `/team?team=<id>`                |
| 从花名册入队 | 优先选已有企业账号               |
| 改队内角色   | 所有者 / 团队管理员 / 企业管理员 |
| 移出         | 不能移所有者                     |
| 复制团队 id  | 给桌面或脚本填 `X-Team-Id` 时用  |

连接默认仍是**全公司共享**，不是每队一套密钥库。按队授权是另一层过滤，见 [连接器与网关](./connections.md)。

## 5. 使用建议

1. 开局先加企业管理员自己以外的 1 个员工，再建模需要的小队，避免人已经在桌面登录却不在任何队。
2. 人事变动：人离开公司用 **停用** 或 **删除**；只换项目用 **移出团队**。
3. 需要第二名企业管理员时，在花名册里把角色改成企业管理员，不要共用一个邮箱。
4. 审计席位用企业审计角色，不要把「只读」理解成队内观察者。

## 6. 常见状态

| 状态               | 含义                   | 建议                         |
| ------------------ | ---------------------- | ---------------------------- |
| Pending            | 已入册，未登录过       | 让对方完成一次验证码登录     |
| 不能删除某管理员   | 他是最后一个 admin     | 先提拔另一人                 |
| 创建团队失败       | 队名含中文或符号不合法 | 改成英数、点、下划线、连字符 |
| 团队页大量英文     | 本页 i18n 未齐         | 功能可用，以按钮实际行为为准 |
| 复选框没有批量操作 | 未做                   | 逐个加人 / 移出              |
