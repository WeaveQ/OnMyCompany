# 排障与边界

本页只写试点里会踩的坑，以及不要对外承诺的能力。

## 1. 排障

| 现象                           | 先看                                                                            |
| ------------------------------ | ------------------------------------------------------------------------------- |
| `localhost:3100/health` 超时   | 是否跑了 `npm run dev`；端口是否被占                                            |
| 打开 `:5180` 空白或 API 不可用 | API 是否在 `:3100`；浏览器控制台跨域 / 代理                                     |
| 解锁失败                       | `OMC_ADMIN_TOKEN` 是否就是你在填的那串                                          |
| 验证码不对                     | 本地默认 `000000`；空库必须先用 `OMC_BOOTSTRAP_ADMIN_EMAIL`；配了 SMTP 则看邮箱 |
| 登录后仍不能加人               | 你不是企业管理员。运维解锁 ≠ 企业管理员                                         |
| 不能删某个管理员               | 他是最后一个 `admin`                                                            |
| 创建团队失败                   | 队名只能是英数、`.`、`_`、`-`                                                   |
| 连接保存了但执行失败           | 策略、连接禁用、队授权、并发帽、配额，逐项看错误码                              |
| 计量没有 LLM                   | Omni 没开，或 `modelRouter.ok` 为 false                                         |
| curl `:3000` 连不上            | `npm run dev` 走 `:3100`；未设 `PORT` 的裸进程才默认 3000                       |
| 桌面填了 `:5180`               | 应填 API 根，例如 `http://127.0.0.1:3100`                                       |

常见错误码：

| 码                                  | 含义                                                     |
| ----------------------------------- | -------------------------------------------------------- |
| `429` `rate_limited`                | G0 并发帽                                                |
| `429` `quota_exceeded`              | 工具次数配额                                             |
| `403` `connection_disabled`         | 组织关掉了该连接                                         |
| `403` `connection_team_denied`      | 该连接有非空授权名单，但没带 `X-Team-Id`，或队不在名单里 |
| `403` `policy_write_via_org_config` | 不要直写 runtime-policy                                  |

## 2. 开局检查

正式试点再勾一遍：

1. 设了 `OMC_ENCRYPTION_KEY` 和 `OMC_ADMIN_TOKEN`
2. bootstrap 邮箱能登录，并且还有第二名管理员或你能接受 last-admin 锁
3. 至少 1 个办公连接或 1 个无鉴权 Action 能跑通
4. 企业设置里允许列表不是无意中的全开
5. 员工用桌面连的是 API 地址，能拉到 Skills / 策略
6. 审计里能看到登录和一次策略或执行事件

更短的成员说明：[MEMBER-ONBOARDING.md](/onmycompany/MEMBER-ONBOARDING)。

## 3. 不要当成已交付

| 项                                   | 现状                          |
| ------------------------------------ | ----------------------------- |
| 管理台里聊天 / 新对话                | 没有，也不会做主路径          |
| 真飞书登录、真飞书连接器生产换票     | stub                          |
| SSO / OIDC                           | 未做                          |
| 每队私有连接密钥库                   | 明确不做；只有共享池 + 瘦授权 |
| 队级策略叠加                         | 未做                          |
| 侧栏按角色隐藏写入口                 | 未做，靠页内禁用和 API 403    |
| 桌面全 runtime 强制走网关            | 延期                          |
| 默认把 LLM 反代进 OMC（G1b）         | 默认关，不要当卖点            |
| 企业审批队列                         | 契约写明非主路径              |
| 公网多租户、托管工作区、员工对话上云 | 不做                          |
| 计量当发票                           | 参考价 + 瘦用量而已           |
| Cloudflare Workers / D1 默认部署     | 不是试点路径                  |

工程计划里有些条目（开局清单、专家页、Skills 多选、按队授权、工具配额）**代码里已经有了**，不要再按「未做」对外说。仍缺的是：审计侧栏收敛、Skills 详情页、MCP 目录页、桌面执行闭环、飞书 / SSO。

文档漂移：`docs/quickstart.md`、部分 BOOTSTRAP 示例仍写端口 `3000`；`INIT-CHECKLIST.md` 仍像 M0。以本手册、`.env.example` 和正在跑的进程为准。

## 4. 安全底线（给人讲的版本）

- 配置和导出不含密钥。
- 连接密钥、OAuth 客户端密钥不回浏览器、不回桌面。
- 模型 Key 放 OmniRoute，不放 OrgConfig。
- 执行要能归因到 `memberId`；要按队统计就带 `X-Team-Id`。
- 未登录桌面不得产生企业流量。
- 许可证：OnMyCompany 非商用源码可见；OnMyAgent 仍是 Apache-2.0。
