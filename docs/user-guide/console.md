# 控制台与角色

管理台是企业管控后台，不是连接器开发者工作室，也不是聊天工作台。

产品入口：`http://127.0.0.1:5180`（本地 `npm run dev`）。

## 1. 两套凭证，不要混

| 层              | 口语                               | 代码                           | 凭证              | 一句话                                   |
| --------------- | ---------------------------------- | ------------------------------ | ----------------- | ---------------------------------------- |
| 平台            | 解锁控制台                         | `ops-admin`                    | `OMC_ADMIN_TOKEN` | 装机、写连接密钥、底层调试。不是人事角色 |
| 企业账号        | 企业管理员 / 企业审计 / 员工       | `admin` / `auditor` / `member` | 邮箱验证码会话    | 花名册上的人                             |
| 团队 membership | 团队所有者 / 团队管理员 / 团队成员 | `creator` / `admin` / `member` | 同一套成员会话    | 某个小队里的人                           |

同一人可以同时拿运维 token 和成员会话，鉴权仍按两套走。右上角齿轮里的身份文案目前固定写「管理员」，**不要当成当前企业角色**。

## 2. 从哪里打开

1. 启动 API 与管理台，见 [快速开始](./quickstart.md)。
2. 若锁了控制台，先填运维 token。
3. 企业页（账号、团队、设置、Skills、专家、计量、审计）要成员会话。本地已解锁时可能静默登录 bootstrap 邮箱；否则用页面上的邮箱 + 验证码。
4. 顶栏团队切换器：具体小队，或（企业管理员 / 企业审计）**全公司**。

## 3. 界面结构

| 区域       | 作用                                                   |
| ---------- | ------------------------------------------------------ |
| 左侧栏     | 固定分组：工作台 / 观测 / 能力 / 配置                  |
| 顶栏切换器 | 当前团队；全公司时「团队」会进 `/org/teams`            |
| 齿轮       | 主题、语言、刷新、去企业设置；运维已配置时才有退出解锁 |
| 主栏内容   | 当前页                                                 |

侧栏**不按角色隐藏**。审计和普通员工也能点进企业设置，保存按钮不可用，API 会 403。

不进侧栏的页：

| 路径                  | 怎么到                                             |
| --------------------- | -------------------------------------------------- |
| `/org/teams`          | 切换到全公司，或团队页里的「全部团队」             |
| `/providers/:service` | 连接器 → 行内连接 / 管理，或「提供商目录（高级）」 |
| `/actions`            | 连接器行内「操作」                                 |

## 4. 企业角色能做什么

|                        | 企业管理员 | 企业审计       | 员工                 | 平台运维                     |
| ---------------------- | ---------- | -------------- | -------------------- | ---------------------------- |
| 花名册增删改           | 能         | 只读           | 不能                 | 不管人事                     |
| 建队、改任意队         | 能         | 列表只读       | 只读本队             | 不管队                       |
| 写企业设置 / 策略      | 能         | 不能           | 不能                 | 不能靠运维 token 冒充        |
| 写连接密钥             | 一般不写   | 不能           | 不能                 | 能                           |
| 启停组织连接、按队授权 | 能         | 不能           | 不能                 | 视控制台会话                 |
| Skills / 专家包写      | 能         | 不能           | 不能                 | 不能替代 org-admin           |
| 自己的 runtime token   | 能         | 不能当执行身份 | 能                   | 控制台 Access 是另一条铸造口 |
| 用量「全公司」         | 能         | 能             | 不能                 | 不适用                       |
| 审计事件 / 导出        | 能         | 能             | 不能                 | 能                           |
| 运行记录               | 全员       | 全员只读       | 产品口径上应只看自己 | 全员                         |

团队层：建队人是 **团队所有者**（`creator`），不能降级或移出。**团队管理员** 可从企业账号池拉人、改本队角色。队内观察者（team `auditor`）还没有权能，界面不必强调。

完整矩阵见 [RBAC.md](/onmycompany/RBAC)。

## 5. 使用建议

1. 先分清「谁解锁了壳」和「谁是企业管理员」。空库第一个管理员只能是 bootstrap 邮箱。
2. 改人走 **企业账号**，改「谁在哪个队」走 **团队**。两个页不要当同一个用。
3. 写策略只走 **企业设置**。API Key 页上的运行时策略编辑器在企业模式下会拒绝保存。
4. 需要看全公司用量或团队列表时，把切换器打到全公司。不要把内部哨兵 `__all__` 当团队 id 去请求。

## 6. 常见状态

| 状态               | 含义                     | 建议                                           |
| ------------------ | ------------------------ | ---------------------------------------------- |
| 解锁页             | 设了 `OMC_ADMIN_TOKEN`   | 用运维 token，不是员工邮箱                     |
| 企业页弹出验证码卡 | 没有成员会话             | 用已在花名册里的邮箱                           |
| 页能打开但保存失败 | 角色不够或走了错误写入口 | 看是不是审计 / 员工，或是否在 API Key 页改策略 |
| 齿轮写着「管理员」 | 文案未接成员身份         | 以 **企业账号** 里的角色为准                   |
