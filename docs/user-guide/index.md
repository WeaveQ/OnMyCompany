# OnMyCompany 使用说明

OnMyCompany 是内网试点用的**组织控制面 + 外发 Gateway**：管人、管组织配置、管办公连接密钥、管外发规矩，并留下审计。员工真正干活的地方是桌面 [OnMyAgent](https://weaveq.github.io/OnMyAgent/docs/guide/company)，不是这个管理台。

这本手册对着 **2026-08 试点主路径** 写，菜单名跟管理台一致。工程细节（HTTP 表、schema、ENV 全表）不在这里展开，文末有链接。

## 1. 一句话理解

| 你要的               | OnMyCompany 怎么做                                         |
| -------------------- | ---------------------------------------------------------- |
| 公司里谁能用 Agent   | 企业账号 + 团队；邮箱验证码登录                            |
| 办公应用钥匙放哪     | 连接器里企业共享；密钥不回传浏览器或桌面                   |
| 员工能调哪些工具     | 企业设置里写允许 / 禁止；保存后同步运行时策略              |
| 员工用哪些技能、专家 | Skills / 专家包下发；桌面只读消费                          |
| 对话模型谁出         | OmniRoute 边车（默认 `127.0.0.1:20128`）；Key 不进本控制台 |
| 出事怎么查           | 计量（工具 vs 模型两本账）、运行记录、审计事件             |

## 2. 状态（诚实）

| 项                                                                         | 状态                                |
| -------------------------------------------------------------------------- | ----------------------------------- |
| 内网管控试点（身份、团队、OrgConfig、Skills、专家包、Gateway、计量、审计） | 服务端可用                          |
| 管理台主路径                                                               | 可用；部分页仍有英文文案            |
| 桌面「设置 → 工作区 → 公司」登录并镜像配置                                 | 最小路径可用                        |
| 桌面每次工具调用都强制走公司网关、带队头、拒绝文案完整                     | 未满，见 [desktop.md](./desktop.md) |
| 真飞书登录 / 飞书连接器生产 OAuth                                          | stub，不要按生产 SSO 承诺           |
| 企业审批队列、公网多租户、默认 LLM 反代                                    | 明确不做主路径                      |

## 3. 和桌面 / 聊天 AI 有何不同

|            | OnMyCompany      | OnMyAgent                            |
| ---------- | ---------------- | ------------------------------------ |
| 定位       | 公司钥匙与规矩   | 本机把活干完                         |
| 入口       | 管理台 `:5180`   | 桌面应用                             |
| 要不要登录 | 企业页要成员会话 | 未连公司也可完整用本机               |
| 有没有聊天 | 没有             | 有（会话 / 专家）                    |
| 密钥       | 只在公司进程     | 本机 BYOK；企业连接后不拿公司 secret |

没有配公司地址时，桌面不得打企业 HTTP。连上之后，桌面不得把组织拒绝改成允许。

## 5. 控制台怎么走

本地默认：API `http://127.0.0.1:3100`，管理台 `http://127.0.0.1:5180`。侧栏人人看得到同一套，写权限在页内和 API 拦截。

```text
工作台     概览 · 企业账号 · 团队
观测       计量计费 · 运行记录 · 审计事件
能力       连接器 · Skills · 专家包 · API Key
配置       企业设置 · 文档
外部       模型路由（打开 OmniRoute，不是本站一页）
```

| 侧栏     | 路径            | 做什么                              |
| -------- | --------------- | ----------------------------------- |
| 概览     | `/overview`     | 健康、用量摘要、管理员开局清单      |
| 企业账号 | `/members`      | 花名册：角色、启用 / 停用 / 删除    |
| 团队     | `/team`         | 当前小队成员；全公司时进团队列表    |
| 计量计费 | `/metering`     | 工具用量 + Omni 模型用量 + 参考价   |
| 运行记录 | `/runs`         | Gateway Action 执行历史             |
| 审计事件 | `/audit-events` | 登录、改配置、改人、token、策略拒绝 |
| 连接器   | `/connections`  | 企业共享办公连接池                  |
| Skills   | `/skills`       | 关联、上传、角色可见                |
| 专家包   | `/experts`      | 启停人设包；公司端不提供对话        |
| API Key  | `/access`       | 铸造 runtime token                  |
| 企业设置 | `/org-config`   | 外发策略、配额、导出（无密钥）      |
| 文档     | `/resources`    | MCP 地址、OpenAPI / Scalar          |

不进侧栏、但能点进去：团队列表 `/org/teams`、提供商 `/providers`、操作 `/actions`（从连接器行进去）。

## 6. 一次开局怎么跑

1. 运维启动进程，必要时用 `OMC_ADMIN_TOKEN` 解锁控制台，在连接器里写入办公密钥。
2. 空库时，`OMC_BOOTSTRAP_ADMIN_EMAIL` 第一次验证码登录成为企业管理员。此后不能自助注册。
3. 企业管理员在 **企业账号** 加人，在 **团队** 把人拉进队。
4. 在 **企业设置** 写下允许 / 禁止与外发模式；在 **Skills / 专家包** 发布目录。
5. 员工在 OnMyAgent **设置 → 工作区 → 公司** 填 `http://127.0.0.1:3100`（或内网正式地址），邮箱验证码登录。
6. Agent 用 runtime token 调 `/v1` 或 `/mcp`。对话模型走 OmniRoute。

逐步操作见 [快速开始](./quickstart.md)。
